# 🧑‍🎓 Student GradeEvaluation System
A console-based Java application designed to take student metadata (name,score,age) and automatically evaluate academic performance into corresponding letter grades.

## 🌟 Key Features & Gameplay Mechanics
1. **Interactice User Data Input**: Reads multi-type console inputs-including text ('name') and primitive integers ('score','age')-using 'java.util.Scanner'.
2. **Conditional Grade Logic**: Utilizes a clear conditional control structure ('if-else if') to evaluate test scores against defined grade boundaries ( e.g.,Grade A for 90+ , Grade B for 80+ ).
3. **Structured Output Report**: Formats and prints a clean,easy-to-read student summary report directly to the terminal.

### 🎮 How to Use

1. Enter the student's name when prompted.
2. Enter the test score (from '0'to '100').
3. Enter the student's age.
4. View the generated **Student Result** report along with the evaluated letter grade!
